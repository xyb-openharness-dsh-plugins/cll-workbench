## 需求假设验证状态（M1 后）
- E1 W&W 观察轨道：**支持（强）**——P1×3（Levin/Dunnion/ASH PRO）+ CLL Society/CLL Support UK 材料均证明观察期记录与情绪需求真实。LDT 只算天数不判读，与 CLL Society"LDT<6 月需与多因素并评"口径一致。
- E2 触发词表：**部分支持**——iwCLL 指征词表有权威底本（ASCO 2025）+ CLL Society 成对患者材料；但"患者不敢问"的动机表述无直接证据（P4），真实价值可能在对症自查，待访谈。
- E3 基因预后档案：**支持（强）**——P1（Campo 2018, Blood）+ P2 纠偏文 + P3（患者自追踪 17p 克隆占比 6%→22%）。三态字段需带"阴性=好"语境标注与检测方法/时间。
- E4 三档临床匹配：**部分支持**——"17p/TP53 常可入组"有 P2 共识 + Reddit 真实入组经历；但"匹配指数"分档呈现无患者证据（P4），访谈验证呈现方式。
- E5 口服药与共病 CIRS：**支持（强，专业侧）**——CIRS-G <6/≥6 直接进治疗决策；虚弱量表预测早期停药。患者/家属自发记录共病与用药冲突的行为零直接证据，为访谈重点。
- E6 MRD 里程碑：**支持（中–强）**——CLL Society 2025 uMRD 措辞（不承诺停药）可直接作词表口径；Mayo Connect 有"达标后要不要停"真实提问；需区分固定疗程 vs 持续用药两种停药叙事，支持"连续两次确认"结构。
