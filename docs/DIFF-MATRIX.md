## 差异化矩阵（场景 → 功能 → 怎么验）· 承接认领 Issue #45 六条

1. W&W 观察轨道 → 验收：无 diagnosis/risk_level 判读列、三态、不出现"该治疗了"类文案（红线扫描脚本断言）。
2. 触发词表卡 → 验收：指征字段与来源版本可断言对应；纯问题清单形态。
3. 基因预后档案 → 验收：未检出/检出/未测三态枚举断言；无判读列。
4. 三档临床匹配 → 验收：匹配指数只算字段重合度；private 三出口代码级过滤；manifest=jsonl=sqlite。
5. 口服药与副作用日志 → 验收：变更事件与服药记录同库同源；时间线可导出。
6. 分系列指标卡 → 验收：分类不进趋势；系列分节 *_title；SVG 根 class="chart"；smoothPath 用 Fritsch–Carlson。

- 计数（同名 1.0、近义 0.5、无关 0，对两仓一级名池）：同名 6.0（看板、病情整理、病情一图秀、临床研究、心理支持、复诊准备）+ 近义 2.0（指标检测↔检查与指标 0.5、口服药与治疗↔治疗历程 0.5、基因与预后档案↔我的分期 0.5、营养与感染预防↔营养支持 0.5）= **Σ 8.0 / 13 = 61.5% ≤ 70%，判据合格**。
- 家族空位页（无关 0 分）：**观察与等待 / 共病与在用药**——差异化主张成立。
