# 项目规格 v0.1 · 小淋宝 LymPal（CLL/SLL）

状态：M1 草案。确认人/日期：G1 待签。不得把本文当成已确认业务。

## 本癌种定位（一段话）

慢性淋巴细胞白血病/小淋巴细胞淋巴瘤（CLL/SLL）患者本人（含 Watch & Wait 未治疗人群）+ 家属代记者的本机病程工作台。CLL 的病程数据形态＝**一条"确诊了却不治疗"的观察等待线 × 定期血常规（ALC 趋势与倍增时间）× 基因预后档案（FISH/TP53/IGHV）驱动的新药试验匹配 × 长期口服药（BTKi/BCL-2i）**。一期十二场景（S1–S12，docs/SCENARIOS.md）。红线：本仓**不回答"该不该治疗/够不够指征/能不能停药"**——治疗指征清单只照抄不判定；决策 100% 留在诊室；数值只抄报告原文。

- 证据与默认值：docs/USER-RESEARCH.md（一手访谈=0，如实声明）；docs/DEV-REQUIREMENTS.md §五（四项默认已选推荐，可回退）
- 家族差异主张：docs/DIFF-MATRIX.md（一级重名率 61.5% 实测 ≤70%，从严口径 76.9% 如实记录（评审修正：原记 92.3% 复算错误）；"观察与等待 + 共病 CIRS + 匹配指数三档匹配"为家族首次）
- 交互路径合同：docs/INTERACTION-DESIGN.md（S1–S12 + CRUD 双通道 + IP1–IP10，IP1 判据：未签认不开 HTML）
- 数据边界草案：血象/生化/分子指标表 + 基因预后档案 + 服药事件 + 副作用自评 + 处方变更 + 共病/在用药 + MRD + 资料夹（G3 前不落正式迁移）

## 医学约束（M1 核数结论，全量见 `research/medical-cll-10-topics.md`）

来源等级：**A 官方指南级**＝《中国 CLL/SLL 诊断与治疗指南（2025 年版）》（中华血液学杂志 2025;46(2):105-112，PMID 40134191，PMC11951213 全文已直取）+ iwCLL 标准（Blood 2008，DOI 10.1182/blood-2007-06-093906）；NMPA 条目为 B 级转述标"待官网复核"。全量见 `research/medical-cll-10-topics.md`。

| 约束 | 内容（原文口径） | 对产品的落点 |
| --- | --- | --- |
| 诊断线 | MBL→CLL：B 淋巴细胞≥5×10⁹/L 持续≥3 月＋形态/免疫表型证实；SLL 为淋巴结肿大而骨髓无浸润证据 | 疑诊档案含 MBL 语境字段；不写"你已是 CLL" |
| 分期 | Binet A/B/C 与 Rai 0–IV 双轨并存 | 分期照抄报告原文双轨，不换算不判进展 |
| 治疗指征 | 2025 中国指南八条（骨髓衰竭/巨脾>6cm/巨块淋巴结>10cm/淋巴细胞 2 月>50% 或 LDT<6 月且初值≥30×10⁹/L/结外受累/AIHA-ITP 激素不佳/B 症状/符合试验入组）；**初值<30×10⁹/L 不能单凭 LDT 作指征（原文）** | 触发词表卡八条逐条对应；LDT 卡只算天数并并排展示该限制原文；零"达标"勾选 |
| 药物 | 一线：BTKi 持续治疗（泽布/伊布/阿可±奥妥珠、奥布）；维奈克拉±抗 CD20 有限疗程；chemo-immune 限适合人群；del(17p)/TP53 优先泽布/伊布（指南推荐语，产品只作词表）；匹妥布替尼用于共价 BTKi 后 | 服药线药名词表按此分组；不排序不推荐 |
| NMPA | 伊布/泽布/奥布/阿可已批（转述）；匹妥布替尼月份矛盾待复核；维奈克拉 CLL 适应症未取得可靠原文；PI3Kδ 未见获批证据（D） | 药名词表标"获批状态待官网复核"，不作筛选条件 |
| 基因预后 | FISH del(17p)/del(11q)/+12/del(13q)；TP53 突变；IGHV 突变状态；复杂核型 | 基因档案三态 + 语境栏；三档匹配输入端 |
| 疗效与 MRD | iwCLL 疗效标准（CR/PR/SD/PD 医生判定）；MRD 敏感度 10⁻⁴～10⁻⁶，流式/NGS | MRD 只照抄 + 词表卡；"测不出≠体内无细胞"事实陈述 |
| W&W 监测 | 无治疗指征者每 2–6 个月随访（病史/体格/血常规+分类/血生化） | 观察轨道节奏参考（非判读线）；无"该复查了"催促文案 |
| Richter | 仅语境词表 + 就医提示；预后数字刻意不收录 | 禁预后暗示 |
| 副作用 | BTKi（出血/感染/房颤/高血压语境）、BCL-2i（TLS 预防语境）；只列词不处置 | 副作用词表按当前用药过滤；TLS 作"就诊要问"语境 |
| 参考区间 | WBC/Hb/Plt 引 WS/T 405-2012（A）；ALC/LDH/β2-MG 无全国统一文件（D） | 指标卡语境栏标"以报告单实验室区间为唯一显示口径" |

**未核实项**（不得写成"通过"）：NMPA 批准文号逐条（B 待官网复核）、中国年发病率具体数字（D）、医保目录（D）、CSCO CLL 章版本号（D）、iwCLL 最新版本年份（D）。

### DSH 原生 AI 对话入口与面板

若工作台接入 DSH 原生 Agent：在全局顶栏提供可见的“AI 对话/打开 AI 对话”入口，写明默认开/关、连接中/已连接/不可用状态、首次点击后的创建或复用规则。原生对话面板可独立隐藏并重新打开；隐藏不结束会话、不清空工作台筛选/表单/滚动状态，也不丢弃原生草稿。面板展开后可调宽，并记录默认宽度、最小/最大边界、键盘操作与持久化范围。

布局必须区分宿主形态：CustomFrame 使用右侧原生面板和可访问的拖动分隔器；默认 35%、范围 25%–45% 是社区基线，项目可依据原型明确确认后调整。split 形态下不得另造第二个宽度状态或假 splitter；宽度只能通过目标 Desktop 支持的宿主布局合同调整。宿主不支持隐藏、重开或调宽时，列出实际限制和替代交互，不得用工作台自制聊天窗冒充原生能力。细节引用 `prompts/DSH-AGENT-PANE-INTEGRATION.md` 与 `docs/20-AGENT-PANE-DESIGN.md`，并记录 HTML 状态稿及目标 Desktop 实测证据。
