# 场景清单（CLL 版 v0.1）

状态：M0 草案，M1 随三路调研定稿；每条挂患者原话占位（见 USER-RESEARCH）。

## S1 观察等待期（Watch & Wait）——主线场景
- 患者原话占位："确诊快两年没吃过药，每次抽完血就回家等，我不知道自己在等什么。"（改写）
- 输入：血常规单（WBC/ALC/Plt/Hb + 日期）；动作：录入/拍照导入、按医嘱间隔排布；输出：ALC 趋势线 + LDT 倍增天数（只算不判）。
- 验收：无"该治疗了"类文案；三态（检出/未检出/未查）。

## S2 治疗指征核对与就诊提问
- 原话占位："复诊就十分钟，想问的话到嘴边就忘。"（改写）
- 输入：指南治疗指征字段照抄（来源+版本标注）；动作：勾选"我想问的"；输出：问题清单可带走。
- 验收：纯问题清单形态，红线扫描通过。

## S3 基因/预后档案维护
- 原话占位："报告写着 del(17p) 阴性、IGHV 无突变，没人讲这跟我的药有什么关系。"（改写）
- 输入：FISH/TP53/IGHV/复杂核型报告原文；动作：建档（未检出/检出/未测三态）+ 看语境栏词表卡；输出：结构化基因档案。
- 验收：无判读列；VUS/未测如实显示。

## S4 三档临床匹配
- 原话占位："病友说我的基因情况可能够新药临床试验，我去哪查、够不够格？"（改写）
- 输入：基因档案 + 年龄/分期等档案字段；动作：本地 sqlite 试验库检索 / AI 协助匹配（一键携带提示词+病情上下文）；输出：匹配结果列表带匹配指数与固定格式。
- 验收：匹配指数只呈现字段重合度，不做入组建议；private 三出口代码级过滤。

## S5 口服药与副作用日志
- 原话占位："每天一粒伊布替尼，哪次调量是因为副作用，本子上早对不上了。"（改写）
- 输入：药名/剂量/起止 + 副作用自评（人话词表）；动作：每日打卡、变更记录带原因原文；输出：依从热力图 + 副作用时间线。
- 验收：变更事件与服药记录同库同源；无判读词。

## S6 共病与在用药（老年语境）
- 输入：CIRS 各系统条目照抄 + 全部在用药；输出：可与 S5 联查的共病用药清单。
- 验收：无判读、无相互作用提示语。

## S7 MRD 里程碑与随访节奏
- 输入：MRD 检测结果照抄（流式/NGS 报告原文）；输出：里程碑轨道 + 词表卡（只解释词义）。
- 验收：不写"可停药/治愈"；三态。
