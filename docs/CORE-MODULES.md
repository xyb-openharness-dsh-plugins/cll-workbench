# 四核心模块（CLL 版 v0.1）

状态：M0 草案；M1 SPEC 定稿后逐项给功能 ID 与验收。四核心继承家族通用能力（病情整理/指标检测/一图秀/临床治疗及试验），此处写 CLL 特有形态。

## 1. 病情整理（我的淋）
- 确诊档案：诊断名（CLL/SLL）、Binet/Rai 分期原文照抄（不判读进展）、诊断日期与医院。
- 基因预后档案：FISH del(17p)/del(11q)/+12/del(13q)、TP53 突变、IGHV 突变状态、复杂核型——未检出/检出/未测三态，报告原文 + 语境栏词表卡（只解释词义）。
- Watch & Wait 状态位：确诊后"医嘱观察/治疗中"两种状态由用户照抄医嘱选择，产品不推断。
- 判定归医生：产品只引用报告原文 + 语境栏。

## 2. 指标检测（分系列指标卡）
- 系列：血象系（WBC/ALC/Plt/Hb）、生化系（LDH/β2-MG/肝肾功能）、分子系（MRD 流式/NGS、IGLV 重排）、体格系（淋巴结/脾脏评估描述）。
- 卡片：正面当前值+语境栏，**动态 3D 反转**看背面详情（系列说明/单位/参考区间来源/历史摘要），趋势折线 smoothPath（Fritsch–Carlson）；ALC 卡附 LDT 倍增天数（只算不判）。
- 硬纪律：分类不进趋势；无 diagnosis/risk_level 类判定列；ORDER BY rowid；显式 null；分类字段有 *_title 分节。

## 3. 一图秀（独立病情一图秀）
- 单份资料复用 ID；**指标选择窗口**可勾选进入一图的指标与系列（用户补充 2）。
- SVG 根 class="chart"；输出可导出。

## 4. 临床治疗与试验
- 治疗事件轨道：口服药（BTKi/BCL-2i 等：药名/剂量/起止/变更原因原文）、化疗/免疫治疗线、输液与随访事件。
- 试验档案/检索/匹配：本地 sqlite 临床库（fetch-cll-trials 四件套）+ 搜索或 AI 协助匹配 → 匹配结果带**匹配指数**与固定格式（展现参考肝癌/胆道癌临床展现图思路，本机无该原型文件，按 starter 27 号指标卡 + Issue #45 描述实现）；关注/来源/资料对照；private 三出口代码级过滤。
- AI 按钮走 xxx:agent-draft 携带提示词+病情上下文。

## 支撑线（一期保留栏目，按用户任务推导）
- 共病与在用药（CIRS 条目照抄）、营养与感染预防语境、心理（W&W 焦虑）、全程安排（复查日历）、收藏回顾、Agent、真实格式导出——M1 定深度。
